# Narrative Forge Content Guidelines

## Philosophy
Narrative Forge supports storytelling. It never tells the story for the Game Master.

## Director's Notes Rules
1. Never describe intentions.
2. Describe only observable details.
3. Never include game mechanics.
4. One idea per note.
5. Use open wording.
6. The Two-Second Rule.
7. Preserve the GM's agency.

## Metadata
- category
- tags
- weight
- conditions
